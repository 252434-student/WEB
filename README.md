Assignment 1 for Web development course.

HTML files, CSS and images folder must exist within the same directory to work.

Three user journeys:

1. To find the opening hours and address user would need to navigate to "Contact" page via navbar tab above. There they can also reserve a table.
2. To look at the menu user would navigate to "Menu" page and scroll through lists of dishes.
3. To find more detailed description user would navigate to "About" page and/or follow the Instagram link in "Contact page".
